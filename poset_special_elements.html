01 · Quick Refresher

What is a Poset?

A set P with a relation ⪯ that is reflexive, antisymmetric and transitive. In a Hasse diagram, going up means "succeeds" — no arrowheads needed.

A poset (P, ⪯) lets us compare some — not necessarily all — pairs of elements. If a line connects x below y, then x ⪯ y, and y is said to succeed x.
👀 Reading a Hasse diagram: higher position = larger element. Only covering relations are drawn — the rest follow by transitivity.
We'll use this rule throughout: top of the diagram → candidates for maximal/greatest, bottom → candidates for minimal/least.
02 · Definition

Maximal Element

a ∈ P is maximal if a ⊀ x for no x in P — i.e. nothing in P strictly succeeds a.

a is maximal ⇔ no element of P strictly succeeds a. On the diagram: no line leads upward from a.
✓ Can have several maximal elements ✓ Every finite poset has ≥1
Example: under divisibility on {1,2,3,4,5,6} — 4, 5, 6 are maximal because nothing left in the set is a multiple of any of them.
03 · Definition

Minimal Element

b ∈ P is minimal if x ⊀ b for no x in P — i.e. nothing in P strictly precedes b.

b is minimal ⇔ no element of P strictly precedes b. On the diagram: no line leads downward from b.
✓ Can have several minimal elements ✓ Bottom-most dots in the diagram
Same poset {1,2,3,4,5,6} under divisibility — 1 is the only minimal element, since 1 divides everything else.
04 · Definition

Greatest Element

a ∈ P is the greatest element if x ⪯ a for every x ∈ P. It is unique when it exists, and is comparable to every element.

The greatest element is a maximal element that beats every single element — watch the highlighted node connect to everyone below it, one hop at a time.
★ Unique if it exists ★ Always the supremum
C = {∅, {a}, {b}, {a,b}} under ⊆  →  greatest element is {a,b}.
05 · Definition

Least Element

b ∈ P is the least element if b ⪯ x for every x ∈ P. It is unique when it exists, and is comparable to every element.

The least element is a minimal element that is beaten by every single element — the ripple now travels upward, reaching every node from the bottom.
◆ Unique if it exists ◆ Always the infimum
Same poset C = {∅, {a}, {b}, {a,b}} under ⊆  →  least element is ∅.
06 · Don't mix them up

Maximal ≠ Greatest, Minimal ≠ Least

A maximal element only has to beat elements it can be compared with. The greatest element must beat everyone.

ConceptRequirementUniqueness
MaximalNo element strictly succeeds it (silent about incomparable elements)Can be many
GreatestIt succeeds / equals every element — always comparable to allExactly one, if it exists
MinimalNo element strictly precedes itCan be many
LeastIt precedes / equals every elementExactly one, if it exists
Rule of thumb: Greatest ⇒ Maximal and Least ⇒ Minimal always. The reverse is not guaranteed — see the poset {2,3,4,6} next: 4 and 6 are both maximal, but neither is the greatest element.

09 · Infinite Poset

Not Every Poset Has a Top

(Z⁺, ∣) — the positive integers under divisibility.

Least element = 1, since 1 ∣ n for every positive integer n.

No greatest element exists — for any integer you pick, a larger multiple is still in Z⁺.
1⟶ 2⟶ 4⟶ 8⟶ 16⟶ ⋯
Same idea in reverse: (Z⁻, ≤) has a maximal element −1 but no minimal element — negative integers run off unboundedly downward.
10 · Recap

Five Points Worth Remembering

Straight from the fine print of Section 9.5.

  • a

    A poset may have no maximal element at all — the natural numbers under ≤ never stop growing.

  • b

    A poset may have more than one maximal or minimal element — {2,3,4,6} under divisibility has two maximal elements, 4 and 6.

  • c

    A maximal element need not be the greatest — 4 and 6 are maximal above, but neither dominates the other, so neither is greatest.

  • d

    A poset can have a maximal element with no minimal element at all, or vice versa — e.g. (Z⁻, ≤) has maximal −1 but no minimal; (Z⁺, ≤) has minimal 1 but no maximal.

  • e

    In a totally ordered set, minimal = least and maximal = greatest — every pair is comparable, so there's nowhere for ambiguity to hide.
