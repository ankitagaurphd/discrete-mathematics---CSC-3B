01 · FOUNDATIONS

What makes a relation a partial order?

A relation R on a set S is a partial order if it satisfies all three rules below. A set S together with a partial order R is a poset, written (S, ⪯). Hover each rule.

1

Reflexive

Every element relates to itself. aRa  ∀a∈S

2

Antisymmetric

If a relates to b and b relates to a, they must be equal. aRb ∧ bRa ⇒ a=b

3

Transitive

Relations chain together. aRb ∧ bRc ⇒ aRc

Think of it like…

"Divides" on positive integers, "is a subset of" on sets — each element precedes, succeeds, or simply isn't comparable to another. ⪯ means "precedes or equals," not literally "less than."

02 · WORKED EXAMPLE 1

Is (Z, ≥) a poset?

Question

Show that the relation ≥ is a partial order on the set of integers, Z.

Solution
✓
Reflexive — a ≥ a for every a ∈ Z.Every integer is greater than or equal to itself.
✓
Antisymmetric — a ≥ b and b ≥ a imply a = b.Two integers can only "outrank" each other both ways if they're equal.
✓
Transitive — a ≥ b and b ≥ c imply a ≥ c.Rankings chain forward.
It follows that ≥ is a partial order on Z, and (Z, ≥) is a poset. In fact every two integers are comparable — making this a total order (a single chain).
03 · WORKED EXAMPLE 2

Is (P(S), ⊆) a poset?

Question

Consider P(S), the power set of a set S — the set of all subsets of S. Show that the inclusion relation ⊆ is a partial order on P(S).

Solution
✓
Reflexive — A ⊆ A for every A ∈ P(S).
✓
Antisymmetric — A ⊆ B and B ⊆ A imply A = B.
✓
Transitive — A ⊆ B and B ⊆ C imply A ⊆ C.
It follows that ⊆ is a partial order on P(S), and (P(S), ⊆) is a poset. For S = {a, b, c}, P(S) has 2³ = 8 elements — shown on the right.
04 · WORKED EXAMPLE 3

Is (Z⁺, /) a poset?

Question

Show that the set Z⁺ of all positive integers under the divisibility relation (written "/") forms a poset.

Solution
✓
Reflexive — n | n for every n ∈ Z⁺.
✓
Antisymmetric — n | m and m | n imply n = m.
✓
Transitive — n | m and m | p imply n | p.
Careful: on the set of all integers, division is not a partial order — a and −a divide each other, but a ≠ −a, so antisymmetry fails.
05 · WORKED EXAMPLE 4

Comparable vs. non‑comparable elements

Question

In the poset (Z⁺, /): are 2 and 4 comparable? Are 3 and 5 comparable?

Solution
✓
Elements a and b are comparable if a ⪯ b or b ⪯ a.
✓
2 and 4: since 2 | 4, they are comparable.
✗
3 and 5: neither divides the other, so they are non‑comparable.
If every pair in a poset is comparable, the poset is totally ordered (a chain). If no two distinct elements are comparable, the subset is an antichain.

07 · WORKED EXAMPLE 5

Totally ordered sets & chains

Question

Show that (Z, ≤) is totally ordered, but (Z⁺, /) is not. Then show that the subset {2, 6, 12, 36} of (Z⁺, /) is a chain.

Solution
✓
For any integers a, b: either a ≤ b or b ≤ a — every pair is comparable, so (Z, ≤) is a totally ordered set (a chain).
✗
In (Z⁺, /), 3 and 5 are incomparable (neither divides the other) — so (Z⁺, /) is not totally ordered.
✓
But {2, 6, 12, 36} ⊂ Z⁺ is totally ordered: 2|6, 6|12, 12|36 — every pair here is comparable, so it's a chain even though the whole poset isn't.
08 · WORKED EXAMPLE 6

Antichains

Question

Show that P = {2, 3, 5, 7} is an antichain in the poset (Z⁺, /).

Solution
✓
An antichain is a subset in which no two distinct elements are comparable.
✓
2, 3, 5, 7 are all prime — none divides another.
✓
So every pair in P is non‑comparable, and P is an antichain.
On a Hasse diagram, an antichain looks like a set of nodes with no path connecting any two of them.
09 · WORKED EXAMPLE 7

Immediate successors & predecessors

Question

Let S = {1,2,3,4,5} with poset (P(S), ⊆). Let A = {2,4}, B = {2,4,5}, and C = {2,3,4,5}. Show A is an immediate predecessor of B, but only an ordinary (non‑immediate) predecessor of C.

Solution
✓
y covers x (y is the immediate successor of x) if x ⪯ y and no z exists with x ⪯ z ⪯ y.
✓
A = {2,4} ⊆ B = {2,4,5}, and no set sits strictly between them — so A is an immediate predecessor of B.
✗
A ⊂ B ⊂ C, so A ⊆ C too — but B sits strictly between A and C. So A precedes C, just not immediately.
10 · HASSE DIAGRAMS

What a Hasse diagram simplifies away

A Hasse diagram represents a poset (X, ⪯) as a picture: vertices are elements, and an edge goes upward from x to y only when y is the immediate successor of x. Loops and transitive edges are never drawn — they're implied. To build one from the full directed graph of a relation:

1
Start with the directed graph

Draw every edge a → b implied by the relation, including loops and transitive shortcuts.

2
Remove all loops

Reflexivity (a R a) is guaranteed for a partial order, so self-loops carry no information — drop them.

3
Remove transitively implied edges

If a R b and b R c, the edge a → c is implied and gets removed — only "immediate successor" links remain.

4
Drop the arrowheads

By convention every remaining edge points upward, so arrows become unnecessary straight lines.

11 · WORKED EXAMPLE 8

Draw the Hasse diagram of (X, /), X = {1,2,3,4,5,6}

QuestionLet X = {1,2,3,4,5,6}. Draw the Hasse diagram of the poset (X, /).

STEP 1 / 3Directed graph of the full relation
1 · Start with the relationDraw every edge a → b where a divides b (a≠b) — including edges implied by transitivity, like 1→4 and 1→6 (dashed here). Watch the pink dashed edges — they're about to be removed.
2 · Drop transitive edgesSince 1→2→4 already connects 1 to 4, the direct edge 1→4 is redundant — and so is 1→6 (via 1→2→6 or 1→3→6). Removing these keeps only immediate-successor links.
3 · Drop arrowheadsEvery remaining edge points strictly upward by convention, so arrows and loops disappear. What's left is the finished Hasse diagram of ({1,2,3,4,5,6}, /).
12 · WORKED EXAMPLE 9

Draw the Hasse diagram for (P(S), ⊆), S = {a,b,c}

QuestionDraw the Hasse diagram for the poset (P(S), ⊆) where P(S) is the power set of S = {a, b, c}.

LEVEL 0 / 3The empty set — our starting point
Level 0 · ∅φ is a subset of every set, so it's the least element — placed at the bottom of every Hasse diagram of a power set.
Level 1 · singletons{a}, {b}, {c} each cover ∅ directly — nothing sits between them, so each connects straight down to ∅.
Level 2 · pairs{a,b}, {a,c}, {b,c} connect upward to exactly the singletons they contain — {a,b} links to {a} and {b}, but not {c}.
Level 3 · the full set{a,b,c} is the greatest element, connected to all three pairs. The finished diamond is the Hasse diagram of (P({a,b,c}), ⊆).
13 · RECAP

Key takeaways

🔗
Poset

A set with a relation that's reflexive, antisymmetric, and transitive — (S, ⪯).

⚖️
Comparable

a and b are comparable if a⪯b or b⪯a. Otherwise non‑comparable.

📶
Chain / Antichain

Chain: every pair comparable. Antichain: no pair comparable.

🪜
Hasse diagram

Drop loops, transitive edges, and arrows — only immediate successors remain.
