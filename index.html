➕ Adding a new lesson

Version 6 keeps the homepage layout automatic. You only need to upload the new HTML file and add one small lesson entry to lessons.js.

  1. Create your new HTML lesson, for example hasse-diagram.html.
  2. Upload that file into this same GitHub repository.
  3. Open lessons.js, copy one existing object, and change its details.
  4. Commit the changes. GitHub Pages will update the same website link.
{ id: "hasse", title: "Hasse Diagrams", category: "posets", type: "Interactive Lesson", description: "Explore and construct Hasse diagrams step by step.", icon: "◇", file: "hasse-diagram.html", search: "hasse diagram poset partial order" }

Important: keep index.html, lessons.js, and your lesson HTML files in the repository root unless we deliberately create folders later.
