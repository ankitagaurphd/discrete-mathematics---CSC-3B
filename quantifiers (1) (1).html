Quantifiers

The Universal and Existential quantifiers — what they mean, and how to move between plain language and symbolic notation.

Presented by  Dr. Ankita Gaur
∀∃
THE IDEA

What is a quantifier?

A predicate like P(x) — say, "x is prime" — isn't true or false on its own; it depends on x. A quantifier is what turns a predicate into a full proposition, by saying how many elements of the domain make it true.

Discrete math uses exactly two of them:

Universal
∀ — "for all"
Existential
∃ — "there exists"
∀
UNIVERSAL QUANTIFIER
∀x P(x)
read as  "for all x, P(x)"  or  "for every x, P(x)"

Claims that a predicate holds for every single element in the domain — no exceptions.

True when
P(x) is true for every x in the domain.
False when
Just one x makes P(x) false — a counterexample.
∀x ∈ ℝ, x² ≥ 0 — "for every real number x, x squared is non-negative"
∃
EXISTENTIAL QUANTIFIER
∃x P(x)
read as  "there exists an x such that P(x)"  or  "for some x, P(x)"

Claims that a predicate holds for at least one element in the domain — just one is enough.

True when
P(x) is true for at least one x in the domain.
False when
P(x) is false for every x — no witness exists.
∃x ∈ ℤ, x + 5 = 10 — "there exists an integer x such that x + 5 = 10"

Negation flips the quantifier: ¬∀x P(x) ≡ ∃x ¬P(x), and ¬∃x P(x) ≡ ∀x ¬P(x). "Not every x has P" means "some x lacks P."

RECAP

∀ vs ∃ at a glance

∀ Universal
Reads: for all / for every
Claims: holds for every element
True if: no exceptions exist
False if: one counterexample found
Negation: ¬∀x P(x) ≡ ∃x ¬P(x)
∃ Existential
Reads: there exists / for some
Claims: holds for one element
True if: at least one witness exists
False if: no element satisfies it
Negation: ¬∃x P(x) ≡ ∀x ¬P(x)
